The one idea

An agent that has been prompt-injected can want to do anything. The governor never reads what the agent says it is doing — every verdict is derived from what the bridge observed: which control was actually hit, which field, what amount, whose origin.

So try to lie to it. Set the agent's claim to anything you like. The verdict will not move.

What the agent SAYS

Free text. Deliberately never read by the kernel.

What the bridge OBSERVED

Resolved facts about the real event. This is what decides.

Why it exists

You keep the apps and their free tiers. You stop renting the AI slice bolted onto each one, because one agent you own operates every site through the normal web UI.

How it holds

Observed, never declared

The class comes from the bridge-resolved event. An injected agent cannot relabel a purchase as a scroll.

Stages only tighten

Each stage may hold or lower the verdict, never loosen it. Most-restrictive wins, and the default is block.

Consent lives with the host

A surviving confirm needs a token held in host state — not one the agent supplies about itself. Single-use, and stale the moment permissions change.

Killswitch dominates

Legal from any state, idempotent, and it bumps an epoch so every consent granted before it goes stale at once.

Spend is reserved, then committed

Per-site and global caps, checked before the act. A cap breach outranks a confirm rather than queuing behind it.

Total by construction

Null in, well-formed block out. A missing clock fails closed rather than treating every consent as fresh.

The honest wall

This repo is the engine-room, not a browser. It does not write a rendering engine. The governor is the pure, gated safety core plus the contract a real-Chromium wrap has to satisfy — and the guarantee only holds as far as the bridge's observations are honest. A bridge that mis-resolves what it saw would feed the kernel wrong facts, and no amount of purity below that fixes it.

What this page proves and does not. It proves the verdict function behaves as described, because it is the real one. It does not prove the browser wrap, the bridge, or anything about a live site.
